# MAPA QUE VENDE

Landing page profissional do **MAPA QUE VENDE**, um produto digital criado para ajudar pequenos negócios a melhorar sua presença no Google Maps, transmitir mais confiança e aumentar as chances de receber contatos de novos clientes.

## Sobre o projeto

O site foi desenvolvido em HTML, CSS e JavaScript puro, com foco em:

- Apresentação do produto;
- Divulgação dos módulos disponíveis;
- Exibição do preço;
- Pagamento por Pix;
- Contato direto pelo WhatsApp;
- Layout responsivo para celular, tablet e computador;
- Publicação simples pelo GitHub Pages.

## Recursos

- Página inicial com apresentação do produto;
- Seção explicando os benefícios;
- Lista dos módulos do material;
- Área de pagamento;
- Botão para copiar a chave Pix;
- Formulário para envio de mensagem pelo WhatsApp;
- Botões de contato direto;
- Menu responsivo;
- Design moderno com tema escuro;
- Compatibilidade com GitHub Pages.

## Como utilizar

1. Faça o download ou clone este repositório;
2. Abra o arquivo `index.html`;
3. Substitua `SUA_CHAVE_PIX_AQUI` pela chave Pix autorizada;
4. Confira o número de WhatsApp no código;
5. Abra o arquivo no navegador para testar.

## Publicação no GitHub Pages

Para publicar o site:

1. Acesse as configurações do repositório;
2. Entre na opção **Pages**;
3. Em **Build and deployment**, selecione:
   - Branch: `main`;
   - Folder: `/root`;
4. Clique em **Save**;
5. Aguarde a publicação do site.

O endereço ficará parecido com:

```text
https://seuusuario.github.io/mapa-que-vende/
```
